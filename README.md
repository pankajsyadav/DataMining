# Data Mining — DSC550

Applied data mining techniques for classification, clustering, association rules, and predictive modeling with a focus on decision science.

## Overview
Coursework and project work demonstrating the full data mining lifecycle: problem framing, data preparation, model building, evaluation, and interpretation for business decisions.

## Core Topics Covered
- Supervised learning: Logistic Regression, SVM, Random Forest, XGBoost
- Unsupervised learning: K-Means, Hierarchical clustering
- Model evaluation: Confusion matrix, ROC curves, precision-recall
- Feature engineering and selection
- Model deployment considerations

## Tech Stack
Python • Scikit-learn • Pandas • NumPy • Matplotlib • Jupyter
